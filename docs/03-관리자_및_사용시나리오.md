# 관리자 계정 및 사용 시나리오

## 관리자 접속

| 항목 | 값 |
|------|-----|
| 주소 | `https://도메인/backend/admin/` (로컬: `http://localhost:8000/backend/admin/`) |
| 기본 아이디 | `admin` |
| 기본 비밀번호 | `jkwithme!2026` |

> ⚠️ 운영 배포 후 **첫 로그인 즉시 비밀번호 변경**(관리자 → 비밀번호 변경). 필요하면 관리자 주소(`admin` 폴더명)를 바꿔 노출을 줄일 수 있습니다.

---

## 시나리오 1 — 방문자가 상담 신청

1. 방문자가 홈페이지의 상담신청 폼에 **성함 / 연락처(SNS) / 문의내용(부위)** 입력 후 전송
2. `submit-endpoint.js`가 값을 `/backend/submit.php`로 전송(AJAX)
3. `submit.php`:
   - **레이트리밋** 확인(같은 IP 과다요청 차단)
   - **입력 검증**(빈값·길이·HTML/URL·허용 부위)
   - `inquiries` 테이블에 저장
   - 관리자 이메일로 **알림 발송**(설정된 경우)
4. 방문자에게 "정상 접수" 안내

> 검증 실패(예: 링크 삽입, 목록 외 부위)는 접수되지 않고 안내 메시지가 뜹니다.
> 이메일 발송이 실패해도 **접수 자체는 저장**됩니다(관리자에서 항상 확인 가능).

## 시나리오 2 — 관리자가 문의 확인·처리

1. 관리자 로그인
2. **문의 목록**(`index.php`): 최신순, 상태(신규/처리중/완료) 필터, 이름·연락처·부위 검색, 페이징
3. **상세 보기**(`view.php`): 접수 내용 확인 → 처리상태 변경, 내부 메모 저장, 필요 시 삭제
4. 상태를 신규 → 처리중 → 완료로 관리

## 시나리오 3 — 이메일 알림 수신자 변경

1. 관리자 → **이메일 알림**(`settings.php`)
2. **수신 이메일**에 여러 명 입력(쉼표/줄바꿈 구분)
3. 발송 방식 선택:
   - **호스팅 기본(mail)**: 설정 불필요, 간편
   - **SMTP(권장)**: 네이버/지메일 SMTP 계정 입력 → 지메일·네이버 도달률↑
4. **테스트 메일 보내기**로 확인

## 시나리오 4 — 관리자 계정 관리

- 비밀번호 변경: 관리자 → **비밀번호 변경**
- 계정 추가/삭제: DB `admin_users` 테이블에서 직접(비밀번호는 `password_hash()` 사용). 필요 시 관리 UI 추가 개발 가능.

## 유지보수 팁

- 상담부위 항목을 바꾸려면: 프론트 폼의 `<select>` 옵션과 `submit.php`의 `ALLOWED_CATEGORIES`를 **함께** 수정.
- 문의 알림을 SMS/카카오로 확장하려면: `mailer.php`와 같은 방식으로 발송 모듈을 추가하고 `submit.php` 저장 직후에 호출.
- 문의 데이터 백업: `inquiries` 테이블을 주기적으로 덤프(관리자 엑셀 내보내기 기능은 추가 개발 가능).
