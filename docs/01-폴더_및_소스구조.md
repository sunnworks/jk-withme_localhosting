# 폴더 및 소스코드 구조

## 최상위 폴더

```
(저장소 루트)
├── site/                 ★ 실제 배포 폴더 (이 폴더를 웹 루트에 업로드)
├── backend/              백엔드 소스 사본(참고용, site/backend 와 동일)
├── tools/                유지보수용 스크립트(통합·정리)
├── docs/                 인수인계 문서(이 문서들)
├── INSTALL.md            설치 가이드
├── README.md             프로젝트 개요
└── (로컬판) setup-local.php, run-local.sh, run-local.bat, README-LOCAL.md
```

> **중요**: 실제로 서버에서 동작하는 것은 `site/` 폴더입니다.
> 루트의 `backend/`는 백엔드만 따로 본 **동일한 사본**(참고용)이며, 수정 시 `site/backend/`와 함께 맞춰야 합니다.

## site/ (배포 웹 루트)

```
site/
├── index.html            메인 페이지
├── about/ doctor/ skin/ nose/ eye-double/ ...   각 진료·소개 페이지(정적)
├── search.html           ★ 사이트 검색 결과 페이지(신규)
├── search-index.json     ★ 검색 색인(전 페이지 제목+본문, 신규)
├── .htaccess             ★ 정적자산 캐시·gzip 압축(신규, 성능)
├── beforeafter/
│   ├── index.html        전후사진(46개 통합)
│   └── ba-filter.js      ★ 전후사진 카테고리 필터(신규, 클라이언트)
├── wp-content/           원본에서 온 정적 리소스(이미지·CSS·JS)
│   ├── uploads/          이미지·업로드 파일
│   ├── plugins/          정적 플러그인 자원(jkwdb, jkw-packs, jkw-popup, bb-plugin ...)
│   └── themes/           테마 자원(bb-theme)
├── cdn.jsdelivr.net/     로컬화한 외부 자산(Pretendard 폰트, Swiper)
├── cdnjs.cloudflare.com/ 로컬화한 외부 자산(FontAwesome, html2canvas)
└── backend/              ★ 백엔드 (아래 참조)
```

> ★ 표시는 원본에 없던 **추가/신규 파일**입니다. 자세한 배경은 `06-추가기능_및_변경이력.md` 참고.

> 폴더명 `jkwdb`, `jkw-packs`, `jkw-popup` 는 원래 외주 플러그인(Haroop)이었던 것을 재단 소유 느낌으로 이름만 바꾼 정적 자원입니다. (기능 로직은 backend가 담당)

## site/backend/ (백엔드)

| 파일 | 역할 |
|------|------|
| `config.php` | DB 접속·사이트 설정 (운영: MySQL / 로컬: SQLite). **비밀 정보 포함, 외부 노출 금지** |
| `config.sample.php` | 설정 예시 파일(복사해서 config.php 작성) |
| `db.php` | PDO DB 연결 + 설정 로더 (`jk_pdo()`, `jk_config()`) |
| `submit.php` | **상담신청 접수 처리** — 검증·레이트리밋·저장·이메일 알림 |
| `security.php` | 입력 검증(HTML/URL/이상값 차단), IP 레이트리밋 |
| `mailer.php` | 자체 이메일 발송(PHP mail + SMTP 클라이언트) |
| `submit-endpoint.js` | 정적 폼 → 백엔드 연결(전송 주소 교체 + 허니팟) + **검색폼→/search.html 라우팅** |
| `.htaccess` | 민감 파일 접근 차단 + 보안 헤더 |
| `schema.sql` | MySQL 스키마(테이블·기본 관리자·기본 설정) |
| `data/` | (로컬판 전용) SQLite DB 파일 위치 |

### site/backend/admin/ (관리자 페이지)

| 파일 | 역할 |
|------|------|
| `auth.php` | 세션 인증 공통(로그인 확인, CSRF 토큰, 이스케이프 헬퍼, 캐시금지) |
| `login.php` / `logout.php` | 로그인 / 로그아웃 |
| `index.php` | 문의 목록(상태 필터·검색·페이징) |
| `view.php` | 문의 상세(상태 변경·메모·삭제) |
| `settings.php` | 이메일 알림 설정(수신자 다중·발송방식·SMTP) |
| `password.php` | 관리자 비밀번호 변경 |
| `header.php` / `footer.php` | 공통 레이아웃 |

## tools/ (유지보수 스크립트)

| 파일 | 역할 |
|------|------|
| `integrate.php` | 정적 사이트에 백엔드 연결 스크립트 삽입 + 절대경로 정리 |
| `strip_trackers.py` | 추적/광고 스크립트 제거 |
| `download-missing.php` / `.ps1` / `-WINDOWS.bat` / `-MAC.command` | HTTrack 미수집 이미지·영상을 원본에서 보충 |
| `missing-assets.txt` | 위 다운로더가 참조하는 누락 파일 목록 |

## 요청 흐름 한눈에

```
[방문자] 상담폼 제출
   └─ submit-endpoint.js 가 /backend/submit.php 로 전송
        └─ submit.php
             ├─ security.php  : 레이트리밋 + 입력검증
             ├─ db.php        : inquiries 테이블에 저장
             └─ mailer.php    : 관리자 이메일 알림
[관리자] /backend/admin/ 로그인 → index.php(목록) → view.php(상세)
```
