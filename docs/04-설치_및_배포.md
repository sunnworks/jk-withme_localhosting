# 설치 및 배포

자세한 단계는 저장소 루트의 **`INSTALL.md`** 를 참고하세요. 이 문서는 개발자용 요약입니다.

## 운영(웹호스팅) 배포 — MySQL

전제: PHP 7.4+, MySQL 5.7+ 지원 호스팅(Apache).

1. **파일 업로드**: `site/` 폴더 내용을 웹 루트에 업로드
2. **DB 생성**: phpMyAdmin에서 `site/backend/schema.sql` 임포트
   - `inquiries` `admin_users` `settings` `rate_limits` 테이블 + 기본 관리자·기본 설정 생성
3. **설정**: `site/backend/config.sample.php` → `config.php` 복사 후 DB 접속정보 입력
   ```php
   'db' => ['host'=>'localhost','port'=>3306,'name'=>'DB명',
            'user'=>'DB아이디','pass'=>'DB비번','charset'=>'utf8mb4'],
   ```
4. **확인**: 홈 `https://도메인/`, 관리자 `https://도메인/backend/admin/`
5. **보안 마무리**: 관리자 비밀번호 변경, `config.php` 권한 확인

## 로컬 테스트 — SQLite (`jk-withme_localthosing`)

전제: PHP만 있으면 됨(MySQL 불필요).

```bash
# Mac/Linux
bash run-local.sh
# Windows
run-local.bat  (더블클릭)
```
- `setup-local.php`가 SQLite DB를 자동 생성(관리자·설정 시드 포함)
- `http://localhost:8000` / 관리자 `http://localhost:8000/backend/admin/`
- 데이터 초기화: `php setup-local.php --reset`
- 로컬에서는 **이메일 실제 발송·일부 외부연동(지도 등)이 동작하지 않음**(정상)

## 환경별 차이 요약

| 항목 | 운영(jk-withme) | 로컬(jk-withme_localthosing) |
|------|-----------------|------------------------------|
| DB | MySQL | SQLite (파일) |
| 설정 | 직접 config.php 작성 | config.php 기본 포함 |
| DB 생성 | schema.sql 임포트 | setup-local.php 자동 |
| 이메일 | 동작(SMTP 권장) | 미발송(테스트만) |

## 배포 시 체크리스트

- [ ] `config.php`에 실제 DB 정보 입력, 외부 접근 차단(`.htaccess` 포함되어 있음)
- [ ] `schema.sql` 임포트 완료
- [ ] 관리자 기본 비밀번호 변경
- [ ] 이메일 알림 수신자/SMTP 설정 및 테스트 발송
- [ ] HTTPS(SSL) 적용 — 로그인·개인정보 보호 위해 필수 권장
- [ ] (권장) 관리자 폴더명 변경 또는 접근 IP 제한
