# JK위드미 홈페이지 — 인수인계 문서

이 문서 묶음은 **JK위드미 홈페이지를 유지보수·운영할 개발자**에게 넘기기 위한 설계·인수인계 자료입니다.

## 배경

- 기존 홈페이지는 외주 개발사가 **워드프레스(WordPress) + Beaver Builder(유료 빌더) + Haroop(문의 플러그인)** 으로 제작했으나, 소스코드를 재단(정강의료재단)에 넘기지 않는 상황입니다.
- 이에 공개된 화면(프론트엔드)을 확보하여 **정적(HTML/CSS/JS) 프론트 + 자체 개발 PHP/MySQL 백엔드**로 재구성했습니다.
- 화면은 원본과 동일하게 유지하되, 상담신청(문의) 접수·관리 기능과 이메일 알림은 **새로 개발**했으며, 외주 플러그인(Haroop) 흔적과 외부 추적 스크립트는 제거했습니다.

## 기술 스택

| 계층 | 사용 기술 |
|------|-----------|
| 프론트엔드 | 정적 HTML/CSS/JS (원본 캡처), jQuery, Swiper, Pretendard/FontAwesome (로컬 호스팅) |
| 백엔드 | PHP 7.4+ (프레임워크 없음, PDO) |
| 데이터베이스 | MySQL 5.7+ / MariaDB 10.2+ (운영), SQLite (로컬 테스트판) |
| 서버 | Apache + PHP (일반 웹호스팅 APM 환경) |

## 저장소 구성

| 저장소 | 용도 |
|--------|------|
| `jk-withme` | **운영(웹호스팅) 배포용** — MySQL 기반 |
| `jk-withme_localthosing` | **로컬 테스트용** — SQLite 기반, PHP만으로 실행(설치 간편) |
| `jk.withme` | 원본 HTTrack 캡처본(참고 보관용) |

> 두 배포 저장소(`jk-withme`, `jk-withme_localthosing`)의 소스는 동일하며, **DB 설정만 다릅니다**(MySQL vs SQLite).

## 핵심 요약

- **배포 방법**: `site/` 폴더를 웹 루트에 업로드 → `schema.sql` 임포트 → `config.php`에 DB정보 입력. (자세히는 `04-설치_및_배포.md`)
- **관리자**: `https://도메인/backend/admin/` — 기본 `admin` / `jkwithme!2026` (**최초 로그인 후 변경 필수**)
- **문의 기능**: 방문자가 상담신청 폼 제출 → DB 저장 → 관리자 조회 + 관리자 이메일 알림
