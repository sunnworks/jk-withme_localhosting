# 추가 기능 및 변경 이력

원본(워드프레스) 사이트를 정적 복제한 뒤, **재단 자체 운영에 맞게 추가·수정한 기능**을 정리합니다.
(개발자가 유지보수 시 "이건 원본에 없던/바뀐 부분"을 파악하는 용도)

---

## 1. 상담신청(문의) 백엔드 — 신규 구현
- 원본은 워드프레스 서버가 처리 → **자체 PHP+MySQL로 재구현**
- 방문자 폼 제출 → `backend/submit.php` → `inquiries` 테이블 저장
- 관리자에서 목록/상세/상태/메모 관리
- 파일: `backend/submit.php`, `backend/submit-endpoint.js`, `backend/admin/*`

## 2. 이메일 알림 — 신규 구현
- 문의 접수 시 관리자 이메일로 자동 발송(다중 수신자, 관리자에서 변경)
- 자체 SMTP 클라이언트(외부 라이브러리 없음) + PHP mail 폴백
- 파일: `backend/mailer.php`, `backend/admin/settings.php` / 표: `settings`

## 3. 보안 강화 — 신규
- 입력 엄격검증(HTML/URL/이상값 차단), IP 레이트리밋(10분 5건), 허니팟
- 관리자: 세션/CSRF/비번해시/캐시금지, `.htaccess` 민감파일 차단·보안헤더
- 파일: `backend/security.php`, `backend/.htaccess` / 표: `rate_limits`

## 4. 사이트 검색 — 신규 구현 (서버 불필요)
- 원본은 워드프레스 서버검색 → **자체 색인 기반 클라이언트 검색으로 대체**
- `site/search-index.json`: 전 페이지 색인(제목+본문, 빌드 시 생성)
- `site/search.html`: 검색 결과 페이지(관련도순, 스니펫 하이라이트)
- 검색폼(`name="s"`)은 `backend/submit-endpoint.js`가 `/search.html`로 라우팅
- **재색인 방법**: 페이지 내용이 바뀌면 색인을 다시 생성해야 함(아래 "유지보수" 참고)

## 5. 전후사진 카테고리 필터 — 신규 구현 (서버 불필요)
- 원본은 워드프레스 ajax(`jkw_ba_filter`)로 서버 필터 → **클라이언트 필터로 대체**
- 6개 정적 페이지(1~6)의 46개 아이템을 메인(`/beforeafter/`)으로 통합
- 각 아이템 제목(`[시술명]`)으로 카테고리 자동 태깅(`data-cat`)
- `site/beforeafter/ba-filter.js`: 카테고리 필터 + "더보기" 페이지네이션
- **한계**: 원본의 2·3차 하위카테고리 데이터는 서버에만 있어 미포함(상위 카테고리 필터만)

## 6. 외부 의존/추적 제거 — 변경
- 외주(하룹) 플러그인 흔적 제거: 폴더·파일·클래스·주석 → `jkw*`
- 추적/광고 스크립트 제거: Google Tag Manager, Criteo, 네이버 wcs, toup(광고)
  - **주의**: 광고 성과추적을 다시 쓰려면 재단 명의 계정으로 재삽입 필요
- 외부 CDN 자산 일부 로컬화(Pretendard CSS·Swiper·FontAwesome·html2canvas)
- 유지되는 외부(기능성): 구글폰트, 카카오/네이버 지도·예약·채널·톡톡, Vimeo

## 7. 성능 최적화 — 신규
- `site/.htaccess`: 정적 자산 캐시(이미지·영상·폰트 1년/CSS·JS 1개월) + gzip 압축
- 모든 지시어 `<IfModule>` 가드 → 모듈 없으면 무시(에러 없음), HTML은 캐시 안 함
- 메인 배너 영상(`0630.mp4`) QuickTime→표준MP4 무손실 재포장(웹 재생 최적화)

## 8. 회원 로그인/가입 — 숨김 처리
- 실사용 회원 기능이 없어(가입정보 수집 수준) **메뉴 숨김**(`.jk-auth-links` display:none)
- 로그인/회원가입 페이지 파일은 남아있으나 네비게이션에서 접근 링크 제거
- 나중에 회원제가 필요하면 자체 구축 가능(가입자 수집형)

## 9. 누락 미디어 보충 도구 — 신규
- HTTrack이 못 받은 이미지·영상을 원본 사이트에서 받아 채우는 도구
- 파일: `tools/download-missing.php` / `.ps1` / `-WINDOWS.bat` / `-MAC.command` / `missing-assets.txt`

---

## 유지보수 시 주의점

- **검색 색인 갱신**: 페이지 텍스트가 바뀌면 `site/search-index.json`을 다시 생성해야 검색에 반영됨.
  (색인 생성 로직은 정적 HTML을 훑어 제목+본문을 추출하는 방식 — 재생성 스크립트 필요 시 요청)
- **전후사진 추가**: 새 전후사진을 추가하려면 `/beforeafter/`의 `.ba-gallery-grid`에 아이템을 추가하고
  제목을 `[카테고리] 시술명` 형식으로 넣으면 필터에 자동 반영됨(`data-cat`은 제목 기반).
- **관리자에서 전후사진 관리 UI**가 필요하면 별도 개발 가능(현재는 정적).
- 세 저장소(운영·로컬·작업)는 화면/기능 소스가 동일 — 수정 시 함께 반영 권장.
