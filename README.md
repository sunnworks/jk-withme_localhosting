# JK위드미 홈페이지 (정적 프론트 + PHP/MySQL 백엔드)

정강의료재단 **JK위드미** 홈페이지를, 개발사 소스 없이 재구성한 프로젝트입니다.

- **프론트**: 원본 사이트(WordPress + Beaver Builder)를 HTTrack 으로 캡처한 정적 화면 그대로 사용 → 화면은 원본과 동일
- **백엔드**: 원본의 상담신청(문의) 기능을 PHP + MySQL 로 새로 구현
  - 문의 접수 → DB 저장
  - 관리자 로그인 → 문의 목록/상세 조회, 처리상태·메모 관리
  - **이메일 알림** → 문의 접수 시 관리자 이메일(다중)로 자동 발송 (자체 SMTP 메일러)
- **외부 의존 제거**: 외주(하룹) 플러그인 흔적 제거, 외부 CDN 자산 로컬화, 추적 스크립트 제거

> 정적 프론트 파일(용량 큼)은 별도 저장소 `sunnworks/jk.withme` 에 있습니다.
> 이 저장소에는 **백엔드 + 통합 도구 + 설치 가이드**가 들어있습니다.

## 폴더 구성

```
backend/                  PHP + MySQL 백엔드
├── schema.sql            DB 스키마 (문의/관리자 테이블 + 기본 관리자)
├── config.sample.php     설정 예시 (복사해서 config.php 로 사용)
├── db.php                DB 연결(PDO)
├── submit.php            상담신청 접수 처리(+이메일 알림 트리거)
├── mailer.php            자체 개발 메일러(PHP mail + SMTP 클라이언트)
├── submit-endpoint.js    정적 폼을 백엔드로 연결하는 클라이언트 스크립트
├── .htaccess             민감파일 접근 차단
└── admin/                관리자 페이지
    ├── login.php / logout.php
    ├── index.php         문의 목록(검색·필터·페이징)
    ├── view.php          문의 상세(상태변경·메모·삭제)
    ├── settings.php      이메일 알림 설정(수신자 다중·SMTP)
    └── password.php      비밀번호 변경

tools/
└── integrate.php         정적 사이트에 백엔드를 연결하는 통합 스크립트

INSTALL.md                설치 가이드 (국내 웹호스팅 기준)
```

비만, 두피/탈모/모발이식, 메디컬 에스테틱, 기타 피부, 기타 성형

## 외부 의존 (의도적으로 유지)

외주(하룹) 흔적과 추적 스크립트, 대부분의 CDN 자산은 제거·로컬화했습니다.
다만 아래 2가지는 **기능상 필요해 의도적으로 외부 로딩을 유지**합니다:

- **구글폰트**(fonts.googleapis.com) — 원본 디자인과 동일한 폰트 유지를 위해
- **다음/카카오 지도**(오시는 길) — 지도는 외부 지도 API가 있어야 렌더링됨

> 완전 무(無)-외부참조가 필요하면 구글폰트는 self-host, 지도는 정적 이미지로 대체 가능합니다.

## 보안

- 모든 DB 접근은 PDO Prepared Statement (SQL 인젝션 방지)
- 출력은 `htmlspecialchars` 이스케이프 (XSS 방지)
- 관리자: 세션 인증, `password_hash`/`password_verify`, 로그인 시 세션 재발급
- 관리자 폼 CSRF 토큰 검증, 공개 폼 허니팟 스팸 차단
